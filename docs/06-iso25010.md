# Đánh giá ISO/IEC 25010

| Đặc tính | Cách đánh giá | Evidence cần lưu |
|---|---|---|
| Functional suitability | RTM, API/E2E pass rate | Test summary report |
| Performance efficiency | k6 p95/error rate | k6 HTML/JSON report |
| Compatibility | Chromium desktop/mobile viewport | Playwright report |
| Usability | Lighthouse, axe, manual keyboard pass | Lighthouse/axe report |
| Reliability | Concurrent booking, error handling | API/DB test log |
| Security | JWT/RBAC/ZAP/headers | ZAP report, API tests |
| Maintainability | TypeScript, modular domain policy, coverage/mutation | CI and coverage |
| Portability | `.env.example`, SQLite, setup steps | Fresh-machine setup evidence |

## Baseline hiện tại

Functional suitability và reliability đã có bằng chứng tự động cho policy thời gian, RBAC, audit log, ẩn room inactive và race condition booking. Security headers, token hết hạn và RBAC đã có test API; ZAP baseline và mutation testing vẫn là bằng chứng pending trước khi kết luận cuối cùng.
