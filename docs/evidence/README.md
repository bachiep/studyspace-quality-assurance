# Historical evidence summaries

Các JSON trong thư mục này là bản ghi lịch sử dùng để giải thích tiến trình kiểm định. Chúng không phải artifact final: một số được tạo ở commit cũ, không có workflow URL hoặc hash artifact tương ứng, và có thể khác số liệu của commit hiện tại.

Kết luận nộp bài chỉ được lấy từ `docs/evidence/final/manifest.json` sau khi workflow quality-evidence hoàn tất, cùng artifact gắn đúng commit SHA. Nếu manifest final chưa có, trạng thái phải ghi **chưa đánh giá** hoặc **BẢN NHÁP**.
